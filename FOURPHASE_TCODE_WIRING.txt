FOURPHASE TCODE WIRING GUIDE
=============================

Goal: send e1-e4 electrode intensities from bREadbeats PMV preview to
Restim via TCode so fourphase playback works over TCP.

Status (2026-04-25):
  - Current local Restim branch expects E1/E2/E3/E4 for fourphase TCode.
  - BreadBeats PMV preview now supports a transport toggle:
      * threephase -> send L0/L1 primary motion
      * fourphase  -> send direct E1/E2/E3/E4 electrode motion
  - Older E0/E1/E2/E3 guidance was stale.


STEP 1 - RESTIM: ASSIGN TCODE TAGS TO e1-e4
-------------------------------------------

File: qt_ui/models/funscript_kit.py

BEFORE:
    AxisEnum.INTENSITY_A: ('e1', '', 0, 1, True, True),
    AxisEnum.INTENSITY_B: ('e2', '', 0, 1, True, True),
    AxisEnum.INTENSITY_C: ('e3', '', 0, 1, True, True),
    AxisEnum.INTENSITY_D: ('e4', '', 0, 1, True, True),

AFTER:
    AxisEnum.INTENSITY_A: ('e1', 'E1', 0, 1, True, True),
    AxisEnum.INTENSITY_B: ('e2', 'E2', 0, 1, True, True),
    AxisEnum.INTENSITY_C: ('e3', 'E3', 0, 1, True, True),
    AxisEnum.INTENSITY_D: ('e4', 'E4', 0, 1, True, True),

Tag scheme: E1=e1, E2=e2, E3=e3, E4=e4

NOTE: If Restim has previously saved settings, the old empty values may be
cached. Reset the funscript kit to defaults in the UI, or delete the related
QSettings entries so it picks up the new defaults.

The TCode router will then create routes for INTENSITY_A-D and incoming
E1/E2/E3/E4 commands will be routed to intensity_a/b/c/d axes.


STEP 2 - BREADBEATS: SEND e1-e4 IN TCodeCommand
-----------------------------------------------

File: pmv_generator.py -> _send_position_at_time()

BreadBeats now supports two PMV preview transport modes:

  - threephase: send alpha/beta as L0/L1 plus V0
  - fourphase: send direct e1/e2/e3/e4 as E1/E2/E3/E4 plus V0

The interpolation already works for any axis name via:
    self._interpolate_axis_at("e1", time_ms)

e1-e4 funscript values are 0-100 and map to 0-9999 for TCode.

Fourphase mapping:

    e_map = {'e1': 'E1', 'e2': 'E2', 'e3': 'E3', 'e4': 'E4'}
    for axis_name, tcode_tag in e_map.items():
        val = self._interpolate_axis_at(axis_name, time_ms)
        if val is not None:
            tags[tcode_tag] = int(val / 100.0 * 9999)

Implementation detail:
  - In threephase mode, BreadBeats serializes L0/L1.
  - In fourphase mode, BreadBeats suppresses L0/L1 and serializes E1-E4.
  - V0 and auxiliary tags still serialize in both modes.


STEP 3 - VERIFY
---------------

Expected TCode output in threephase mode:
  L05000I33 L15000I33 V09999I33

Expected TCode output in fourphase mode:
  V09999I33 E17500I33 E22500I33 E35000I33 E41000I33

What to check:
  - Load a funscript that has .e1/.e2/.e3/.e4 companion files.
  - In bREadbeats PMV Generator, set Preview T-Code Mode to fourphase.
  - Play the preview.
  - Restim should show electrode intensities updating.
  - Restim monitoring should show live intensity values on A-D.

Troubleshooting:
  - If e1-e4 do not appear, verify Restim funscript kit settings show
    E1/E2/E3/E4 in the T-Code axis column.
  - If values seem wrong, check the 0-100 -> 0-9999 scaling.
  - Restim range for INTENSITY is 0-1, and TCode 0000-9999 maps to 0.0-1.0.


REFERENCE
---------

Restim TCode parsing (net/tcode.py):
  - Format: {2-char-tag}{digits}[I{interval_ms}]
  - Example: E15000I33 -> axis E1, value 0.5, over 33 ms
  - Value = digits / 10^len(digits), e.g. 5000 -> 0.5000

Restim axis routing (qt_ui/tcode_command_router.py):
  - Loads FunscriptKitModel, builds mapping from 2-char tags to axes
  - route_command() looks up tag in mapping, then calls axis.add(value, interval)

bREadbeats TCode sending (network_engine.py):
  - TCodeCommand.to_tcode() builds V0 and optional L0/L1/E1-E4/P0/C0/P1/P3
  - tcode_tags append as: " {tag}{val:04d}I{dur}"
  - Sent over TCP with trailing \n
